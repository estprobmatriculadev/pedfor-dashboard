# Task 03 — Backend

## Objetivo

Implementar a camada responsável pelas regras de negócio e disponibilização dos dados para o frontend.

---

## Responsabilidades

O backend deve:

- receber requisições;
- validar parâmetros;
- aplicar regras de negócio;
- consultar a camada de dados;
- transformar os resultados necessários;
- retornar respostas padronizadas;
- tratar erros.

---
