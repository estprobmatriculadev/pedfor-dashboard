# 6. `docs/tasks/04.dados.md`

Este eu considero **um dos mais importantes para um dashboard**, porque evita que o sistema tenha gráficos bonitos com indicadores calculados incorretamente.

```md
# Task 04 — Dados

## Objetivo

Definir, preparar, validar e disponibilizar os dados utilizados pelo dashboard.

---

# 1. Fonte dos dados

Documentar:

- origem;
- tabela/arquivo;
- campos;
- periodicidade de atualização;
- responsável;
- limitações;
- volume aproximado.

---

# 2. Dicionário de dados

Para cada campo utilizado:

| Campo | Tipo | Descrição | Obrigatório | Origem |
|---|---|---|---|---|
| id | string | Identificador | Sim | Fonte |
| data | date | Data do registro | Sim | Fonte |
| categoria | string | Categoria | Não | Fonte |
| status | string | Situação | Não | Fonte |

O dicionário real deve ser preenchido conforme a fonte utilizada.

---

# 3. Qualidade dos dados

Validar:

- registros duplicados;
- valores nulos;
- valores inválidos;
- inconsistências;
- tipos;
- datas;
- chaves;
- relacionamentos.

---

# 4. Transformações

Toda transformação deve ser documentada.

Exemplo:

```text
Fonte
  ↓
Limpeza
  ↓
Padronização
  ↓
Agregação
  ↓
Indicadores
  ↓
Dashboard
