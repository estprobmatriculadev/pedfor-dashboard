# Task 01 — Fundação do Projeto

## Objetivo

Preparar a estrutura técnica inicial do dashboard para permitir o desenvolvimento das camadas de dados, backend, frontend e testes.

---

## Escopo

### Deve ser definido

- stack utilizada;
- estrutura de diretórios;
- gerenciamento de dependências;
- configuração de ambiente;
- padrão de componentes;
- padrão de serviços;
- padrão de acesso aos dados;
- estratégia de autenticação, caso necessária;
- estratégia de testes.
