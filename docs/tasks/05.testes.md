# Task 05 — Testes e Validação

## Objetivo

Garantir que o dashboard esteja funcionando de acordo com a especificação e que os indicadores apresentados sejam confiáveis.

---

# 1. Testes unitários

Testar principalmente:

- regras de negócio;
- cálculos;
- transformações;
- filtros;
- validações;
- funções utilitárias.

---

# 2. Testes de dados

Validar:

- quantidade de registros;
- duplicidades;
- valores nulos;
- tipos;
- agregações;
- cálculos;
- relacionamentos.

---

# 3. Testes de API

Validar:

- respostas;
- parâmetros;
- filtros;
- erros;
- autenticação;
- paginação;
- casos sem dados.

---

# 4. Testes de interface

Validar:

- carregamento;
- filtros;
- atualização dos gráficos;
- tabelas;
- navegação;
- estados vazios;
- mensagens de erro.

---

# 5. Testes de responsividade

Validar:

- desktop;
- tablet;
- celular.

---

# 6. Testes de regressão

Após qualquer alteração relevante, verificar se:

- KPIs continuam corretos;
- gráficos continuam corretos;
- filtros continuam funcionando;
- API continua respondendo;
- dados continuam consistentes.

---
